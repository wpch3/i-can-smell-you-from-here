# 《I Can Cook For You From Here》
### 中文名：《我在这儿就能闻到你了》 · 恋爱向同人续篇

> 原作：*I Can Smell You From Here* by **catproblem9735**
> 本作是非商业同人作品，一切原作角色与世界观版权归原作者所有。

---

## 1. 一句话概念

**上一次约会，你为了不被吃掉而撒谎。这一次约会，你要决定：敢不敢让她闻出真话来。**

原作是关于「如何活过一顿饭」的恐怖视觉小说。本作是它的**恋爱向平行续篇**：同样是那个烛光、木墙、只有两个人的餐桌，但敌人不再是她的食欲，而是**你自己的诚实**。恐怖感不来自"她会不会吃我"，而来自"她会不会因为太了解我而不再想要我"。

---

## 2. 世界观衔接

三条时间线任选其一进入（由序章的选择决定）：

| 入口 | 承接原作结局 | 开场状态下 |
|---|---|---|
| **A. 她留下了你的号码** | Ally / Crush 系结局 | 三周后她主动发来消息："今晚我做饭。" |
| **B. 你逃了，但没删掉她** | Rival / 侥幸生还 | 你一直盯着那个对话框，直到它先亮起来 |
| **C. 你说的是真话**（隐藏） | 诚实路线 | 她记得你说的每一个字，一句都没忘 |

三种入口进入同一个第一章，但**她的开场台词、厨房里已经摆好的东西、以及"她知道多少"完全不同**——这是本作的第一层重玩价值。

---

## 3. 重制：第一次约会（Chapter 0「重访第一夜」）

原作的第一夜保留，但做**恋爱向优化改编**，目标是从"生存判定"变成"关系建立"：

1. **删掉同质化试探**：原作里连续几轮"解释你是什么东西"的选项合并为 3 个有情感重量的问题：*你为什么来？你怕我吗？你希望我是什么？*
2. **每个选项都有情感后果，而非生死后果**：回答得好，她会靠近一点（画面构图会变——这是本作的核心演出，见第 5 节）。
3. **新增「点菜」路线**：原作里你只能被她点。重制版你可以反过来问她"你想吃什么"，权力反转，是全作最甜也最冷的一句台词所在。
4. **嗅觉交互**：鼠标划过画面，可"闻"到环境气味文本（蜡油、铁锈、她的香水底调）。这些气味全部是后续章节的伏笔。
5. **结局收敛为三档"她记住你的方式"**，并直接接续第二章，不再需要重开游戏。
6. **节奏**：原作 15–30 分钟，重制版压缩到 **约 10 分钟**，但信息密度更高。

## 5. 核心系统

### 5.1 三量表（不出现在 UI 上，只通过演出反馈）
- **香气（Scent）**——她有多喜欢你的味道（吸引力）
- **信任（Trust）**——她相信你说了多少真话
- **疑心（Doubt）**——她在算你哪句是编的

恋爱向的关键设计：**香气和疑心可以同时上升**。让她对你更好奇，往往意味着让她更危险。玩家永远无法把所有量表都拉满，这是本作的悲剧内核。

### 5.2 承诺账本（Promise Ledger）
你随口说的每一句"下次我给你做…"“我会告诉你…"都会被记录。第四章她会**逐条复述**。兑现了的承诺会变成温柔的回报；没兑现的会变成菜单上的一行字。
（这是对原作「一致性」机制的恋爱化改造。）

### 5.3 嗅觉感知（Smell）
按住空格开启"嗅"模式：画面转为低饱和＋气味标签浮现。用于解谜、看穿谎言、以及在最终章分辨**她身上是否还有别人的味道**。

### 5.4 构图演出
她越靠近，立绘越大、越偏画面中心、照在她脸上的烛光越暖。她越疏远，画面越暗、越空、桌子越宽。**玩家不需要看数值，看她的距离就知道自己做得好不好。**

## 6. 结局

| 结局 | 条件 | 一句话 |
|---|---|---|
| **早餐**（True Romance） | 高信任 + 兑现全部承诺 | 你成为她愿意留在天亮之后的人。 |
| **同类**（Dark Romance） | 高香气 + 全程说真话 + 接受她的提议 | 你放弃做人的资格，换她永远不腻。 |
| **餐前**（Bittersweet） | 高信任 + 低香气 | 她动了心，于是决定放你走——这是她能给出的最温柔的事。 |
| **第二道菜**（隐藏） | 嗅到全部 12 个气味伏笔 + 第四章说出那句原作台词 | 揭示"她为什么偏偏选中你"——从第一次约会之前就已经开始了。 |

## 7. 美术与音效方向（风格一致性守则）

- **底色**：暖褐 / 深棕 / 近乎黑的木墙，全画面 70% 在暗部，只有烛光是暖的。
- **笔触**：厚涂数字油画，保留笔刷毛边与纸纹颗粒，不用干净赛璐璐线稿。
- **人物**：半写实动漫脸——苍白皮肤、偏大的深色杏眼、浅金色波波头、蓝色挂脖上衣＋浅蓝丝巾。表情差分靠**眼神和嘴角**，不做夸张 Q 版。
- **UI**：底部深色横条 + 无衬线小字号对白，右侧一个极小的白色下三角；整体压低饱和度，不与画面抢戏。
- **音效**：lo-fi 钢琴底噪、木地板、油锅、远处车辆。她说话时环境音会**低下去半个音量**——观众会下意识更专注地听她。
- **禁忌**：不要明亮的粉红恋爱色，不要闪亮特效，不要大字号夸张音效字。

## 8. 技术实现

- 纯前端单页视觉小说引擎（HTML / CSS / JS，无构建步骤），Arena 预览即可直接玩。
- 立绘分层：`背景 / 角色 / 烛光叠加 / 暗角 / 颗粒 / 对话框`。
- 剧本数据与引擎分离（`story/*.json`），方便后续扩写。
- 中英双语，默认中文。
- 存档：localStorage，记录已解锁章节、气味伏笔、结局。
