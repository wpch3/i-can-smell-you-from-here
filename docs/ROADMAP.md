## M1 Vertical Slice —— 重制第一次约会（Ch0）
目标：浏览器打开即玩，10 分钟一周目，3 个结局。

### 技术方案（已定）
- **单页网页 VN 内核**：`index.html` + `engine.js`（约 500 行）+ `story/ch0.json`
- 素材分层（CSS z-index 顺序）：
  `bg` → `character` → `candlelight overlay` → `grain` → `vignette` → `dialogue`
- 剧本数据与引擎分离，语法贴近 Ren'Py `label`，便于日后迁移
- 存档：`localStorage`（章节、已见台词、气味图鉴、承诺账本）
- 双语：`zh` / `en` 键值对，默认中文

### Ch0 内容结构（重制版第一次约会）
1. **Fumble 匹配页**（复刻原作开场，重绘）→ 接受邀请
2. **进店**：她已经在等，桌上有烛台和那个笔记本
3. **三个有重量的问题**（替代原版密集的"你是什么东西"盘问）
   - 你为什么来？
   - 你怕我吗？
   - 你希望我是什么？
4. **点菜反转**：反问她"你想吃什么" —— 全章最甜也最冷的一句
5. **收尾**：三档"她记住你的方式"
   - 记住了你的味道（← 接 Ch1）
   - 记住了你的名字（← 接 Ch1，路线不同）
   - 记住了你的谎话（← 隐藏，接 Ch3）
6. **心理评估页**：不做数值，改成她写给你的一小段"批注"

### 演出（Demo 的卖点）
- 立绘随好感**推近 / 变亮 / 偏轴心**，玩家不看数值也能读空气
- 烛光呼吸（overlay 透明度 4s 周期）
- 鼠标悬停桌面物件出现"气味文本"（蜡油 / 铁锈 / 她的香水底调）
- 台词逐字淡入，她停顿处**故意留 0.6 秒空白**
