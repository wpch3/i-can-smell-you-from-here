### 脸的唯一来源：`base_v1.png`

**这条是本项目绘画一致性的核心规则。**

早期两版都错了：
- 第一版让各造型「借 `expr_*.png`」→ 换马尾时头发变回短发
- 第二版让各造型「用自己的图 img2img 出表情」→ 每过一次 img2img，五官就被磨平一格：
  下颌变宽、鼻梁塌成一块、嘴唇失去光泽、皮肤发灰。25 格里有 17 格比 base 老五六岁，
  风格直接散掉（用户就是看着这个提出「脸部没有统一风格」的）。

现在 `build_sprites.py` 的做法：

```
底图(本造型的衣服/发型)  ← 衣服、发型、光位
    ↓ paste_face()       把 base_v1 的脸按椭圆遮罩贴上去（下沿收在下巴以上）
    ↓ paste_expression() 再把 expr_*.png 的「眉线以下」贴上去（重羽化 0x34，避开刘海）
    ↓ BEAUTY             统一调色（unsharp + 饱和 +16% + 对比 +7）
成品格子
```

**脸永远只有一张**，表情差异只来自眼/嘴那一小块，所以 27 格看起来是同一个人在换表情。

踩过的三个坑：
1. 脸框下沿超过 y≈355 会把脖子贴过去 → 围裙组领口叠成「双丝巾」。
2. 表情框上沿高过眉线会把刘海擦掉一块（羽化越重越明显）。
3. 做过一次「全局色彩匹配」，参考区域含大量橙发，结果把马尾/盘发的肤色拉爆 → 已撤销；
   各造型底色差异小到可以接受，宁可不动。

### Beauty pass 参数

```python
BEAUTY = ["-unsharp", "0x1.3+0.9+0.02",      # 眼线、唇锋重新立起来
          "-modulate", "100,116,100",         # 饱和 +16%：皮肤透气血，蓝布不回灰
          "-brightness-contrast", "1x7"]      # 高光才"亮得起来"
```

所有格子（含 `blink_patch.png`）用同一套参数，风格才不会散。

### 一条踩过的坑：表情**必须**用各造型自己的图

早期做法是「每套造型都借 `expr_*.png` 当表情」。结果换到马尾/盘发时，
立绘会突然变回短发——因为 `expr_*.png` 是拿 `base_v1` 做 img2img 出来的，
**头发是 base 的短发**，只有脸是同一个。

现在每套造型的表情都用它自己的底图 img2img（`ponytail_amused.png` 这类），
发型和衣服永远属于本造型。代价是表情集不通用，好处是不会串妆。

> 另一个命名遗留：`outfit_apron.png` 其实是**蓝吊带**，真正的围裙是 `apron_flat.png`。
> `GROUPS` 里围裙组已经改用后者当底图。

## 二、要不要做「动态立绘」和「底层」？

**要，但分三层做，不要一上来就上 Live2D。**

| 层 | 做法 | 成本 | 本项目的判断 |
|---|---|---|---|
| **L1 层叠动画** | 精灵表切表情 + 眨眼补丁 + 呼吸位移 + 推近 | 几乎为零（已完成） | ✅ 必做，性价比最高 |
| **L2 刚性分层** | 把头发、丝巾、高光拆成 3–10 个独立图层，每层**只做整体位移/旋转**，不做网格变形 | 低（从现有图切层，不需要重画） | ✅ **已实现 3 层**（刘海 / 丝巾 / 高光） |
| **L2+ 骨架绑定** | Live2D / Spine 网格变形 | 高（要重画 15–20 层且会撕裂笔触） | ❌ 不做，见 `DYNAMIC_SPRITE_OPTIONS.md` |
| **L3 逐帧** | 手绘 8–12 帧循环（发丝、烛光、呼吸） | 高（每帧都是完整重绘，跟厚涂风格冲突） | ❌ 不做。厚涂风格逐帧容易抖 |

### 为什么现在不做 Live2D

1. **风格冲突**：本作是厚涂油画，Live2D 的强项是干净线稿 + 平涂（日系赛璐璐）。厚涂做网格变形，边缘笔触会被拉伸、出现"橡皮泥感"。
2. **资产前置条件没满足**：Live2D 需要**分层 PSD**（前发 / 后发 / 脸 / 眼白 / 瞳 / 睫毛 / 眉 / 嘴 / 身体 / 丝巾 / 衣服…）。现在只有一张扁平 PNG，要拆层等于重画。
3. **收益错配**：这个游戏的表演核心是**距离、光、和停顿**，不是头发飘动。把预算花在「她靠近」的构图和烛光呼吸上，观感提升远大于加 Live2D。

**所以动态立绘的策略是：先用 L1 把「活人感」做出来（已完成），再用「切层 + 刚性运动」做 L2（已完成 3 层）。**
关键点是不做网格变形——厚涂的笔触拉一下就会变成橡皮泥，而整层平移/旋转不会。

## 三、「底层」需要什么

不是指引擎底层，而是**角色分层底图**。真正做 L2 时，需要按下面的图层顺序出图（每层都要黑底/透明对齐同一坐标系）：

```
01 后发（含被肩挡住的部分）
02 身体（含脖子、肩、手臂）
03 衣服（挂脖上衣）
04 丝巾（两条：颈圈 + 垂下的尾端，分开做，便于分别摆动）
05 脸部底（含耳朵、下颌阴影）
06 眉 ×2
07 眼白 ×2
08 瞳孔/虹膜 ×2（可单独做视点移动）
09 上下睫毛 / 眼线 ×2
10 嘴 ×3（闭 / 微张 / 笑）
11 前发（刘海，会遮住部分眉眼，必须在最上层）
12 高光层（烛光反射，单独一层可以做呼吸明暗）
```

关键点：
- **刘海必须在最上层**，否则眨眼时睫毛会盖到头发上，一眼假。
- **丝巾尾端单独一层**，因为它是最容易做「轻微摆动」的部分，成本最低、效果最好。
- **高光层单独一层**，可以直接用透明度动画模拟烛光闪烁，不需要重画。

## 四、M1 已实现的引擎能力

- `setExpression('sly')` — 切精灵表格子，切换不跳位（所有差分共用同一裁切框）
- 眨眼：每 3–7 秒一次，闭合 110ms，用 `blink_patch.png` 叠在眼睛位置
- 呼吸：`translateY(±2.4px) + scale(±0.35%)`，周期 16 秒
- 推近：`lean_in` / `lean_back` / `push_slow` 三个 transform，和剧本 `show idimya <表情> at lean_in` 对应
- 立绘高度 = 舞台高度 × 0.92，自动适配窗口
