## 二、要不要做「动态立绘」和「底层」？

**要，但分三层做，不要一上来就上 Live2D。**

| 层 | 做法 | 成本 | 本项目的判断 |
|---|---|---|---|
| **L1 层叠动画** | 精灵表切表情 + 眨眼补丁 + 呼吸位移 + 推近 | 几乎为零（已完成） | ✅ 必做，性价比最高 |
| **L2 骨架绑定** | Live2D / Spine：把头发、丝巾、胸口、手臂分成独立图层做网格变形 | 中（要把现在这张单张立绘**拆成 15–20 个图层**，等于重画一次） | ⏳ 等剧本定稿后再做，否则每次改动作都要重绑 |
| **L3 逐帧** | 手绘 8–12 帧循环（发丝、烛光、呼吸） | 高（每帧都是完整重绘，跟厚涂风格冲突） | ❌ 不做。厚涂风格逐帧容易抖 |

### 为什么现在不做 Live2D

1. **风格冲突**：本作是厚涂油画，Live2D 的强项是干净线稿 + 平涂（日系赛璐璐）。厚涂做网格变形，边缘笔触会被拉伸、出现"橡皮泥感"。
2. **资产前置条件没满足**：Live2D 需要**分层 PSD**（前发 / 后发 / 脸 / 眼白 / 瞳 / 睫毛 / 眉 / 嘴 / 身体 / 丝巾 / 衣服…）。现在只有一张扁平 PNG，要拆层等于重画。
3. **收益错配**：这个游戏的表演核心是**距离、光、和停顿**，不是头发飘动。把预算花在「她靠近」的构图和烛光呼吸上，观感提升远大于加 Live2D。

**所以动态立绘的策略是：先用 L1 把「活人感」做出来（已完成），等 Ch1–Ch4 的剧本和表情需求稳定后，再决定要不要为关键场景做 1–2 张 L2 精修立绘。**

## 三、「底层」需要什么

不是指引擎底层，而是**角色分层底图**。真正做 L2 时，需要按下面的图层顺序出图（每层都要黑底/透明对齐同一坐标系）：

```
01 后发（含被肩挡住的部分）
02 身体（含脖子、肩、手臂）
03 衣服（挂脖上衣）
04 丝巾（两条：颈圈 + 垂下的尾端，分开做，便于分别摆动）
05 脸部底（含耳朵、下颌阴影）
06 眉 ×2
07 眼白 ×2
08 瞳孔/虹膜 ×2（可单独做视点移动）
09 上下睫毛 / 眼线 ×2
10 嘴 ×3（闭 / 微张 / 笑）
11 前发（刘海，会遮住部分眉眼，必须在最上层）
12 高光层（烛光反射，单独一层可以做呼吸明暗）
```

关键点：
- **刘海必须在最上层**，否则眨眼时睫毛会盖到头发上，一眼假。
- **丝巾尾端单独一层**，因为它是最容易做「轻微摆动」的部分，成本最低、效果最好。
- **高光层单独一层**，可以直接用透明度动画模拟烛光闪烁，不需要重画。

## 四、M1 已实现的引擎能力

- `setExpression('sly')` — 切精灵表格子，切换不跳位（所有差分共用同一裁切框）
- 眨眼：每 3–7 秒一次，闭合 110ms，用 `blink_patch.png` 叠在眼睛位置
- 呼吸：`translateY(±2.4px) + scale(±0.35%)`，周期 16 秒
- 推近：`lean_in` / `lean_back` / `push_slow` 三个 transform，和剧本 `show idimya <表情> at lean_in` 对应
- 立绘高度 = 舞台高度 × 0.92，自动适配窗口
