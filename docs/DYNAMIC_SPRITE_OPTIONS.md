# 厚涂立绘怎么动：Live2D 之外的 6 条路

> 结论先说：**厚涂不适合 Live2D 的网格变形，但完全能"动"**。
> 本项目已实现路线 1 + 2 + 3 + 4（4 用"从现有图切层"的办法做到，**没有重画**）；路线 6 部分已实现。

---

## 为什么厚涂不适合 Live2D

Live2D 的核心是**把一张图切成网格做顶点变形**。它假设：
- 边缘干净（线稿或平涂），变形后边缘仍然干净
- 相邻色块之间过渡简单，拉伸不会露馅

厚涂恰好相反：**笔触本身是信息**。你把一块刷痕拉长 15%，笔触的颗粒、走向、边缘毛糙全被破坏，观感立刻变成"橡皮泥"/"融化的塑料"。同理，Spine 的网格变形也有这个问题。

**所以厚涂的动态化，正确方向不是"变形"，而是"分层 + 位移 + 光"** —— 让每一层保持刚性，只做整体移动 / 旋转 / 透明度变化，笔触就不会被撕开。

## 六条路线（按性价比排序）

### 1. 眨眼补丁 ✅ 已实现
单独一张"闭眼"层，只露眼部，羽化边缘，叠上去 110ms。
- 成本：1 张图
- 效果：玩家感知最强的"活人感"，因为它打破了静止
- 实现：`blink_patch.png` + `#lid` 层，每 3–7 秒一次

### 2. 呼吸位移 ✅ 已实现
立绘整体做 16 秒周期的 `translateY(±2.4px) + scale(±0.35%)`。
- 成本：0（纯代码）
- 关键：**幅度必须小到玩家意识不到在动，只觉得"她没死"**。超过 5px 会变成"飘浮"

### 3. 视点跟随 ✅ 已实现
鼠标在画面上移动时，立绘整体反向微移 1.2%。
- 成本：0
- 原理：人类视觉对"随我而动的物体"会读作"活物"。这不是眼球转动，但错觉足够
- 想要真眼球转动，需要单独的眼睛层（见路线 4）

### 4. 分层刚性动画 ✅ 已实现（3 层试点）
把立绘拆成若干层，每层**只做整体位移/旋转**，不做网格：

| 层 | 动法 | 幅度 |
|---|---|---|
| 前发（刘海） | 轻微左右摆 + 旋转 | ±1% / ±0.5° |
| 后发 | 反相位摆 | ±1.2% |
| 丝巾尾端 | 摆动，最明显的一层 | ±2.5% / ±2° |
| 眼白+瞳孔 | 视点跟随（真正的眼球转动） | ±3px |
| 上下睫毛 | 眨眼时快速位移 | 一次性 |
| 嘴 | 三态切换（闭/微张/笑） | 切换而非变形 |
| 身体 | 呼吸 | 已完成 |
| 高光层 | 透明度呼吸，模拟烛光 | 0.85–1.0 |

**成本**：一次性重绘分层 PSD（15–20 层），之后所有表情复用。
**为什么比 Live2D 好**：刚性运动不会破坏笔触，厚涂风格完整保留。

#### 本项目的落地做法：不重画，直接切层

`tools/build_layers.py` 从 `base/calm` 这一格里切出三块，用羽化遮罩做边缘过渡，
透明通道用 `-compose DstIn`（不是 `CopyOpacity`，后者会把透明区变成黑块）：

| 层 | 裁切框（在原图坐标） | 羽化 | 动法 | 幅度 |
|---|---|---|---|---|
| `layer_bangs` 刘海 | `110,10 390×188`（**刻意避开眼睛**） | 14px | `translateX` 双正弦 + `rotate`，origin 50% 4% | ±0.55% + 0.18% / ±0.35° |
| `layer_scarf` 丝巾 | `322,262 150×560` | 18px | 反相位横摆 + 纵摆 + 旋转，origin 22% 2% | ±1.7% + 0.5% / 纵向 0.12× / ±1.6° |
| `layer_spec` 高光 | `250,230 300×220` | 26px | `opacity` 呼吸 + `mix-blend-mode: screen` | 0.13 ± 0.04 ± 0.012 |

三条曲线都用**不同周期**（2.7s / 1.13s / 3.4s / 1.9s / 4.6s / 1.7s / 0.53s），
互相不成整数倍，所以循环感极弱——这是"看起来不像 GIF"的关键。

> **踩过的坑**
> 1. 刘海裁切框**不能把眼睛包进去**，否则摆头时眼睛跟着漂，一眼假。
> 2. `-compose CopyOpacity` 处理羽化遮罩会把原本透明的区域变成不透明黑块，
>    叠上去是个黑框；必须先把遮罩 `-alpha copy`，再用 `-compose DstIn`。
> 3. 旧的 `#hairSway`（`clip-path` 近似）和新的分层动画如果各自维护 `transform`，
>    会互相覆盖导致抖动 → 统一到**单个 RAF 循环**里按层写入。

### 5. 逐帧手绘 ❌ 不做
每帧完整重绘。厚涂单帧画一天，8 帧循环 = 一周一个动作，而且帧间笔触必然抖动。
- 例外：**只对 1–2 个关键 CG 做 3–4 帧**（比如她抬眼看你的那一下），成本可控，冲击力最大

### 6. 全屏后处理 ✅ 部分已实现
不动立绘，动画面：烛光呼吸（明暗）、颗粒、暗角、景深。
- 成本：0
- 效果：观众会以为是角色在动，其实是光在动
- 已实现：`candleBreath()` 立绘明暗呼吸 + 暗角闪烁

## 本项目的最终方案

```
L1 层叠（已完成）   眨眼 + 呼吸 + 视点跟随 + 烛光明暗                      ← 观感已"活"
L2 分层刚性（已完成）刘海 / 丝巾 / 高光三层，只做位移 + 旋转 + 光呼吸      ← 本轮落地，3 层试点
L2+ 扩层（可选）   后发 / 瞳孔 / 嘴三态，需要补出对应独立层                ← 看下一章需求
L3 关键帧（M4）    1–2 个情绪爆点做 3 帧手绘                              ← 只做最值得的
```

**L2 目前的局限**：只有 `base/calm` 切了层，所以三层动画**只作用于 base 造型**。
换到 apron / coat / ponytail / hairup 时引擎会把三层 `display:none` 掉、退回 L1
（眨眼 + 呼吸 + 视点 + 烛光）——叠着 base 的短发刘海在别的造型上比不动更糟。

要全线化，`build_layers.py` 里对每组各切一次即可，接口不用改。

**不做的**：Live2D、Spine、逐帧循环。理由是它们都会破坏厚涂的笔触，而这个项目的画风就是它的全部卖点。
