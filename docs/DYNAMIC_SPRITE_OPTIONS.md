# 厚涂立绘怎么动：Live2D 之外的 6 条路

> 结论先说：**厚涂不适合 Live2D 的网格变形，但完全能"动"**。
> 本项目已实现路线 1 + 2 + 3（零额外美术成本）；路线 4/5 等剧本定稿后再上。

---

## 为什么厚涂不适合 Live2D

Live2D 的核心是**把一张图切成网格做顶点变形**。它假设：
- 边缘干净（线稿或平涂），变形后边缘仍然干净
- 相邻色块之间过渡简单，拉伸不会露馅

厚涂恰好相反：**笔触本身是信息**。你把一块刷痕拉长 15%，笔触的颗粒、走向、边缘毛糙全被破坏，观感立刻变成"橡皮泥"/"融化的塑料"。同理，Spine 的网格变形也有这个问题。

**所以厚涂的动态化，正确方向不是"变形"，而是"分层 + 位移 + 光"** —— 让每一层保持刚性，只做整体移动 / 旋转 / 透明度变化，笔触就不会被撕开。

---

## 六条路线（按性价比排序）

### 1. 眨眼补丁 ✅ 已实现
单独一张"闭眼"层，只露眼部，羽化边缘，叠上去 110ms。
- 成本：1 张图
- 效果：玩家感知最强的"活人感"，因为它打破了静止
- 实现：`blink_patch.png` + `#lid` 层，每 3–7 秒一次

### 2. 呼吸位移 ✅ 已实现
立绘整体做 16 秒周期的 `translateY(±2.4px) + scale(±0.35%)`。
- 成本：0（纯代码）
- 关键：**幅度必须小到玩家意识不到在动，只觉得"她没死"**。超过 5px 会变成"飘浮"

### 3. 视点跟随 ✅ 已实现
鼠标在画面上移动时，立绘整体反向微移 1.2%。
- 成本：0
- 原理：人类视觉对"随我而动的物体"会读作"活物"。这不是眼球转动，但错觉足够
- 想要真眼球转动，需要单独的眼睛层（见路线 4）

### 4. 分层刚性动画 ⏳ 下一步（推荐）
把立绘拆成 8–10 层，每层**只做整体位移/旋转**，不做网格：

| 层 | 动法 | 幅度 |
|---|---|---|
| 前发（刘海） | 轻微左右摆 + 旋转 | ±1% / ±0.5° |
| 后发 | 反相位摆 | ±1.2% |
| 丝巾尾端 | 摆动，最明显的一层 | ±2.5% / ±2° |
| 眼白+瞳孔 | 视点跟随（真正的眼球转动） | ±3px |
| 上下睫毛 | 眨眼时快速位移 | 一次性 |
| 嘴 | 三态切换（闭/微张/笑） | 切换而非变形 |
| 身体 | 呼吸 | 已完成 |
| 高光层 | 透明度呼吸，模拟烛光 | 0.85–1.0 |

**成本**：一次性重绘分层 PSD（15–20 层），之后所有表情复用。
**为什么比 Live2D 好**：刚性运动不会破坏笔触，厚涂风格完整保留。

> 本项目已用**同一张精灵表的"头发区域裁切"**近似了路线 4 里的"前发摆动"（`#hairSway` 层：`clip-path` 只露头部，做 ±0.9% 摆动 + ±0.5° 旋转）。没有独立发层时，这是零成本的做法；有了独立发层后可以直接替换，接口不变。

### 5. 逐帧手绘 ❌ 不做
每帧完整重绘。厚涂单帧画一天，8 帧循环 = 一周一个动作，而且帧间笔触必然抖动。
- 例外：**只对 1–2 个关键 CG 做 3–4 帧**（比如她抬眼看你的那一下），成本可控，冲击力最大

### 6. 全屏后处理 ✅ 部分已实现
不动立绘，动画面：烛光呼吸（明暗）、颗粒、暗角、景深。
- 成本：0
- 效果：观众会以为是角色在动，其实是光在动
- 已实现：`candleBreath()` 立绘明暗呼吸 + 暗角闪烁

---

## 本项目的最终方案

```
L1 层叠（现在）   眨眼 + 呼吸 + 视点跟随 + 头发裁切摆动 + 烛光明暗   ← 已完成，观感已"活"
L2 分层刚性（M3） 独立发层 / 丝巾层 / 眼层，只做位移旋转            ← 等剧本定稿
L3 关键帧（M4）   1–2 个情绪爆点做 3 帧手绘                        ← 只做最值得的
```

**不做的**：Live2D、Spine、逐帧循环。理由是它们都会破坏厚涂的笔触，而这个项目的画风就是它的全部卖点。
